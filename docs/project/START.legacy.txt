🚀 DÉMARRAGE RAPIDE

1. Installation
   npm install

2. Configuration
   # Créer .env.local avec:
   DATABASE_URL="postgresql://..."
   GEMINI_API_KEY="sk-..."

3. Base de données
   npx prisma generate
   npx prisma migrate dev --name init

4. Lancement
   npm run dev
   # http://localhost:3000

5. Initialiser idées
   curl http://localhost:3000/api/seed
